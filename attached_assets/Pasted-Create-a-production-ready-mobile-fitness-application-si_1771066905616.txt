Create a production-ready mobile fitness application similar to Strava but integrated with a real-time territory conquest gaming system.

🏃 Core Concept

The app should allow users to:

Track running, jogging, cycling, walking, hiking

After each activity, generate a GPS route map

Automatically convert a closed GPS route into a territory polygon

The area inside the closed track becomes the user’s claimed territory

If another user completes a route that:

Overlaps an existing territory

Or fully encloses it

And covers at least 60% of the area

Then:

The territory ownership transfers to the new user

The previous owner loses that territory

🔔 Mandatory Territory Steal Notification System (NEW REQUIREMENT)

When a user’s territory is stolen:

The previous owner must instantly receive:

Push notification

In-app real-time alert

Notification stored in database

Notification content example:

“⚔️ Your territory in Mumbai has been conquered by @username”

Show:

Area lost

Date & time

Activity type used to conquer

Link to view the new territory map

Also notify the new owner:

“🏆 You successfully conquered a territory!”

Maintain:

Territory conquest history log

Timeline of attacks & defenses

🌍 Real-Time Global Map System

The app must include a full-screen interactive world map where:

Users can zoom out and see the entire globe

Each user’s claimed territories are color-coded

Clicking on a territory shows:

Owner name

Total area

Number of activities used to claim it

Date of conquest

Conquest history

Include:

Leaderboard overlay

Smooth animated transitions
